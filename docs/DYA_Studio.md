# DYA Studio

cormoran さんの [DYA Studio](https://studio.dya.cormoran.works) で、キーマップを画面から変えます。インストールは要りません。

| 版 | 変えられるもの |
|:-|:-|
| **DYA 版** | キーの割り当て・レイヤー名・**同時押し・マクロ** |
| 公式版 | キーの割り当て・レイヤー名（ZMK Studio と同じ） |

## 接続
1. Chrome か Edge で [DYA Studio](https://studio.dya.cormoran.works) を開きます（iPhone・iPad は Bluefy というブラウザで Bluetooth 接続ができます）
2. 「USB」を選んで、Enigma_01 のシリアルポートを選びます（Bluetooth でもつなげます）
3. 「ロックされている」と表示されたら、Enigma_01 で **B を押したまま、D の位置（studio_unlock）** を押してロックを解除します

キーボードがなくても、「Demo」で画面を試せます。

## キーマップを変える
キーを選んで割り当てを変え、保存します。保存した内容はキーボード本体に残ります。

1.0u のファームを書き込んだ 1.5u・2.0u の人は、最初に物理配置（レイアウト）を自分の配列に切り替えてください。

## 同時押しを変える（DYA 版）
「Macros & Combos」の画面で、同時押しの一覧を見たり、変えたり、足したりできます。

- 初期の同時押し（14個）は「Default」と表示されます。変えたものは「Overridden」になり、「Reset to Default」で初期に戻せます
- 同時押しは24個まで登録できます（初期の14個＋10個）
- 押すキーは、画面のキーの並びをクリックして選びます

## マクロを作る（DYA 版）
1. 「Macros & Combos」の画面で、名前を入れてマクロを作ります。作ると、番号（スロット）が付きます
2. キーマップの画面で、割り当てたいキー（Macro のレイヤーがおすすめ）に「Runtime Macro」を選び、その番号を入れます

マクロは8個まで作れます。
